# 🚀 Canva 自动化 v1.0.1 - canva.com AI 自动化 [![English](https://img.shields.io/badge/English-blue)](README.md) [![Tiếng Việt](https://img.shields.io/badge/Tiếng%20Việt-green)](README_vi.md)

**Canva 自动化** 是一款强大的生产力工具，用于在 Canva AI (`canva.com`) 上自动化您的创作流程。告别手动逐个复制和输入提示词——实现流程自动化，排队数十或数百个提示词，大规模生成回复、文本和图片。

-----

## ✨ 主要功能

* **🚀 批处理：** 排队大量提示词，让扩展程序自动运行发送并处理整个 Canva 内容生成过程。
* **💬 文本处理（文本转文本）：** 按顺序处理多个文本提示词，自动组合文本生成任务或开始新对话。
* **💬 原料转文本（图片 + 文本输入）：** 上传图片（原料）并配合提示词，生成详细的文本分析或回复。
* **🖼️ 文本生成图片批处理：** 批量生成多张高质量图片，支持各种常用宽高比（16:9、9:16、1:1、3:4、4:3）。
* **🖼️ 图片生成图片：** 使用 AI 和自定义提示词转换和增强现有图片。
* **⚙️ 专业自动化控制：**
    * **随机等待：** 在提交提示词之间设置智能间隔，以优雅、安全地应对速率限制（rate limits）。
    * **自动下载：** 生成完成后自动下载图片和文本结果。
    * **自动更改文件名：** 根据配置自动对下载的文件进行重命名。
* **📊 侧边栏队列监控：** 在 Chrome 侧边栏中通过活跃队列、延迟倒计时和直观的状态栏实时监控进度。
* **📂 有序文件管理：** 按您的项目将下载的文件自动分类到 Chrome 下载目录下的独立子文件夹中。
* **📄 表格导入：** 支持直接从 `.txt`、`.xlsx` 或 `.csv` 文件批量导入提示词并支持列预览。
* **🎯 范围运行：** 选择并执行特定范围内的提示词（例如：从第 5 个到第 20 个提示词）。
* **🌐 多语言支持：** 英语、越南语、中文、韩语、西班牙语、日语。

## 📖 使用指南

### 开始使用

1. **访问 Canva AI**
   - 打开 [canva.com/ai](https://www.canva.com/ai) 页面。
   - 确保您已登录您的 Canva 账号。

2. **打开扩展程序**
   - 点击 Chrome 工具栏中的扩展程序图标。建议固定以便快速访问！
   - 此时将打开扩展程序侧边栏。

3. **配置批量设置**
   - 在 **控制** 标签页中，您可以设置 **保存到文件夹** 的名称以整理您的下载文件。
   - 在 **设置** 标签页中，自定义您的默认模式、默认宽高比、下载首选项以及随机等待时长。

4. **选择模式**
   - 点击模式按钮之一：**文本处理**、**原料转文本**、**文本转图片** 或 **图片转图片**。

---

### 各模式使用说明

#### 1. 文本处理模式
1. 选择 **文本处理** 模式。
2. 在输入框中输入提示词（每个提示词之间用 **空行** 分隔）。
3. 或者点击 **上传 .txt 文件** 或 **上传 .xlsx / .csv** 来导入提示词列表。
4. （可选）使用 **范围运行** 选择要执行的提示词索引范围。
5. 点击 **运行** 开始批量自动处理文本提示词。

**示例提示词：**
```
为一款极简风格的竹制水壶撰写一段引人入胜的产品描述。

为一家环保咖啡品牌创作 5 个吸引人的社交媒体帖子创意。

总结 2026 年现代 UI/UX 设计趋势。
```

#### 2. 原料转文本模式
1. 选择 **原料转文本** 模式。
2. 拖放或点击上传您的源图片（支持 PNG、JPG、GIF，单张最大 10MB）。
3. 输入描述您需求的提示词（用空行分隔）。
4. （可选）勾选 **自动添加角色图片**，系统将根据文件名自动匹配角色图片。
5. 点击 **运行**。

#### 3. 文本生成图片模式
1. 选择 **文本转图片** 模式。
2. 输入详细提示词（用空行分隔）。
3. 在设置中配置所需的 **默认宽高比**（16:9、9:16、1:1、3:4、4:3）和 **图片模型**。
4. 在设置中配置 **每条提示词生成图片数**（1 到 50）。
5. 点击 **运行** 开始批量生成图片。

**示例提示词：**
```
雨中闪烁着霓虹灯的未来赛博朋克城市，电影级光影，极致细节。

秋天宁静的日式庭院，红枫叶绚丽，锦鲤池塘。
```

#### 4. 图片生成图片模式
1. 选择 **图片转图片** 模式。
2. 上传您想要修改或增强的源图片。
3. 输入描述修改或风格调整的提示词。
4. 在设置中配置 **默认图片模式选项**（*新图片* 或 *编辑图片* 以链式合成）。
5. 点击 **运行**。

## ⚙️ 设置配置

访问侧边栏中的 **设置** 标签页，微调自动化行为：

* **默认模式：** 设置打开时的默认创作模式。
* **默认宽高比：** 可选 16:9 (YouTube)、9:16 (Shorts/Reels)、1:1 (正方形)、3:4 (人像) 或 4:3 (风景)。
* **每条提示词生成图片数：** 设置每个提示词生成的图片数量（1 至 50）。
* **并行提示词：** 设置同时处理的提示词数量。
* **随机等待：** 设置处理提示词之间的最小和最大随机等待时间（秒）。
* **图片模型：** 选择用于图片生成任务的 AI 模型。
* **默认对话模式选项：** 选择默认对话模式（*新对话* 或 *当前对话* 以合并回复）。
* **默认图片模式选项：** 选择默认图片输入模式（*新图片* 或 *编辑图片* 以链式编辑）。
* **失败时最大重试次数：** 指定生成失败时的重试次数（1 到 20 次）。
* **自动下载质量（图片）：** 设置自动下载的图片质量（*不下载*、*1k*）。
* **语言：** 在 English、Tiếng Việt、中文、한국어、Español 和 日本语 之间进行切换。
* **下载设置：** 自动将生成的输出分类整理到 Chrome 下载目录下独立的项目子文件夹中。

## 💡 提示与最佳实践

1. **应对限制：** 如果您的 Canva 账户遇到速率限制，请增加控制标签页中提示词之间的 **随机等待** 时间。
2. **表格导入：** 使用 `.xlsx / .csv` 导入工具，可以轻松预览并从电子表格列中选择导入提示词。
3. **范围运行：** 利用运行按钮旁边的起始/结束范围输入，无需重新编辑文本即可处理提示词列表的子集。
4. **项目文件夹命名：** 在控制标签页中为您的项目文件夹命名，以便将所有文件整洁地归类在一起。

## 🔧 故障排除

| 问题 | 解决方案 |
| :--- | :--- |
| **扩展程序未激活** | 确保您位于 [canva.com/ai](https://www.canva.com/ai)。如有需要请刷新页面（F5 或 Ctrl+R）。 |
| **生成错误** | 点击扩展程序界面上的 **修复错误** 按钮。扩展程序将根据设置的“失败时最大重试次数”自动尝试重新提交。 |
| **下载无效** | 请在 Chrome 浏览器设置中 **关闭** “下载前询问每个文件的保存位置”设置。 |
| **账号及授权问题** | 确认您已登录 `canva.com` 以及扩展程序的方案账户（通过方案横幅）。 |
